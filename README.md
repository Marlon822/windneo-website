# WindNeo - 奢华手表上链器与保险箱品牌网站

## 项目介绍

这是为 WindNeo 品牌打造的奢华手表上链器和保险箱官方网站。网站参考了 Enigwatch 的设计风格，以现代奢华和极简主义为设计理念，打造高端品牌形象。

## 如何使用

1. **直接打开**: 在浏览器中打开 `index.html` 文件即可查看网站

2. **本地服务器** (推荐):
   ```bash
   # 使用 Python
   python -m http.server 8000
   
   # 使用 Node.js
   npx http-server
   ```

3. **部署到生产环境**: 将文件上传到任何静态网站托管服务（如 Vercel、Netlify、GitHub Pages）
